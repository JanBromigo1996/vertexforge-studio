Is it safe to download? In short: yes.Kann ich es bedenkenlos laden? Kurz gesagt: ja.

VertexForge does nothing hidden: no internet connections, no background services, no changes outside its own folders, and every line of code is public. New programs from private developers without a paid signing certificate are often flagged by a few “machine-learning” scanners. These are automatic guesses, not findings. Want to be extra careful?   2. The cause was foundDie Ursache wurde gefunden

    The window library used by the app hid a small Microsoft file (WebView2Loader.dll) inside the program and loaded it straight from memory. Malware uses the same trick, so scanners react to it (hence “FakeMsApp”). The setup also carried the app as an uncompressed embedded program and copied itself into the install folder.Die Fenster-Bibliothek der App hat eine kleine Microsoft-Datei (WebView2Loader.dll) im Programm versteckt und direkt aus dem Arbeitsspeicher geladen. Schadsoftware nutzt denselben Trick, deshalb reagieren Scanner darauf (daher „FakeMsApp“). Außerdem trug das Setup die App als unkomprimiertes eingebettetes Programm und kopierte sich selbst in den Installationsordner.

  3. Fixed for this releaseFür dieses Release behoben

    The DLL is now a normal, Microsoft-signed file next to the program, loaded the ordinary way. The setup unpacks a compressed package like other installers, uses a separate uninstaller and no longer copies itself. Debug information stays in the program. All changes are in the commit history.Die DLL ist jetzt eine normale, von Microsoft signierte Datei neben dem Programm und wird ganz normal geladen. Das Setup entpackt ein komprimiertes Paket wie andere Installer, nutzt ein eigenes Deinstallationsprogramm und kopiert sich nicht mehr selbst. Debug-Informationen bleiben im Programm. Alle Änderungen stehen in der Commit-Historie.

Is VertexForge safe to use?Ist VertexForge sicher?

Yes, as far as anyone can check: the code is open, every release is scanned and checksummed, and the app works completely offline. All scanner results, including false alarms, are published in the security section.Ja, soweit man das prüfen kann: Der Code ist offen, jedes Release wird geprüft und mit Prüfsummen versehen, und die App arbeitet komplett offline. Alle Scanner-Ergebnisse, auch Fehlalarme, stehen im Sicherheitsbereich.

Why does Windows or my antivirus warn me?Warum warnt Windows oder mein Virenscanner?

VertexForge is new and not code-signed, so Windows does not “know” it yet. Some antivirus engines also guess based on patterns. Compare the SHA-256 checksum with the table above. If it matches, the file is the published one. Please report the warning with the false alarm form.VertexForge ist neu und nicht signiert, deshalb „kennt“ Windows es noch nicht. Manche Virenscanner schätzen außerdem anhand von Mustern. Vergleiche die SHA-256-Prüfsumme mit der Tabelle oben. Stimmt sie, ist es die veröffentlichte Datei. Bitte melde die Warnung über das Fehlalarm-Formular.

Is it really free?Ist es wirklich kostenlos?

Yes. No subscription, no account, no ads. The MIT license allows personal and commercial use.Ja. Kein Abo, kein Konto, keine Werbung. Die MIT-Lizenz erlaubt private und kommerzielle Nutzung.

Does VertexForge use AI?Nutzt VertexForge KI?

The tool itself contains no AI at all and never creates images, models, textures or text. Its code was written with the help of Claude, an AI assistant, which is why it may contain bugs. More about this in About.Das Programm selbst enthält keinerlei KI und erzeugt niemals Bilder, Modelle, Texturen oder Texte. Sein Code wurde mit Hilfe von Claude, einem KI-Assistenten, geschrieben. Deshalb kann er Fehler enthalten. Mehr dazu unter Über.

Can several people work on one project?Können mehrere Leute an einem Projekt arbeiten?

Yes. Share the project in a folder your team already syncs (OneDrive, Dropbox, Google Drive, Nextcloud or a network drive) via File ▸ Share in a team folder. Others open it with File ▸ Open team project. Changes are merged every few seconds, conflicts are kept as copies. There is no server and no account.Ja. Teile das Projekt über Datei ▸ Im Team-Ordner teilen in einem Ordner, den dein Team ohnehin synchronisiert (OneDrive, Dropbox, Google Drive, Nextcloud oder Netzlaufwerk). Die anderen öffnen es mit Datei ▸ Team-Projekt öffnen. Änderungen werden alle paar Sekunden zusammengeführt, Konflikte bleiben als Kopie erhalten. Es gibt keinen Server und kein Konto.
